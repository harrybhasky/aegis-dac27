# DAC 2027 submission (Research Track)

Deadlines (dac.com/2027/program/research-manuscript-submissions): **abstract Nov 11, 2026, 5 PM PT**
(title + ~100-word abstract + all co-authors with affiliations/emails + conflicts, on https://softconf.com/dac27/research);
**manuscript Nov 18, 2026, 5 PM PT**. No grace period.
Format: IEEE conference template, double column, 9-10 pt, PDF, **6 pages + 1 page of references only**
(non-reference text on page 7 = desk reject). Double-blind: no names/affiliations anywhere incl. PDF metadata; cite own
work in third person. If LLM-generated content is used, a section titled "Content Generated by AI" is required.

## Build
    python3 make_bib.py      # refs.bib from ../related_work.bib (+ extras.bib)
    python3 gen_tables.py    # tables/*.tex + tables/numbers.tex from the logged runs (re-run as runs finish)
    tectonic -X compile main.tex

Every number in the tables and in \N... macros is generated; prose numbers taken from finished runs are listed in
`experiments/key_findings/`. Red `\pend{...}` markers = things to fill once runs finish; `grep -n 'pend{' main.tex`.
`MANUAL_AUDIT` in gen_tables.py holds the three hand-audited CDC verdicts, each citing its key-findings file.
`abstract_registration.txt` = text for the Nov 11 form.
